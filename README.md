# Велотаймер

Интервальный таймер для тренировок на велотренажёре: две программы (пиковая и высокая мощность), подсказки по каденсу, мощности и сопротивлению, звуковые и голосовые сигналы, запись результатов и отчёт для тренера.

Открыть: https://snegurkirill.github.io/Velotimer/

Всё приложение — один файл `index.html` без зависимостей и сборки. Прогресс и записи хранятся в `localStorage` браузера.

Идеи и планы доработок: [BACKLOG.md](BACKLOG.md).
